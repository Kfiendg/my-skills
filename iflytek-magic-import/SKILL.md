# Magic 录音笔音频导入

把用户提供的独立录音生成 `iFLY_YYYY-MM-DD HH_MM_SS` 目录，包含同名 `.mp3`、`.sbc`、`.mark`、`.mode`、`.sbc.md5` 五个文件。此配方已在用户 Magic 录音笔上通过 30 秒测试及约 64 分钟完整录音的手机导入测试；不保证所有型号和固件通用。

## 时间必须先确认

先运行脚本 `inspect`，按真实容器/编码识别音频，不能仅相信扩展名。检查格式及流的时间元数据；创建时间也可能只是转码或导出时间，必须结合来源判断。

- 用户已经明确提供的录制日期时间优先。
- 仅在文件内元数据可靠地代表录制时间时，才可直接采用，并说明来源。完整、无歧义的文件名时间可作线索；不能据此填补缺失年份、日期或时刻。
- **无法从文件本身可靠获取完整录制时间时，必须先询问用户这条录音的录制日期与时间，再转换。** 告诉用户已知部分和缺失部分。不得用文件系统创建/修改时间、当前时间或零点代填。只有用户明确允许，才可使用约定的占位时刻。
- 多条录音分别确认；时间冲突时询问用户，不自行加一秒。将确认结果显式传入 `--recorded-at`。时间按用户录制地的本地时间命名；存在跨时区歧义时确认。

## 执行

依赖 Python 3、FFmpeg（含 libmp3lame、sbc 编码器）、ffprobe。脚本从 PATH 查找，也可传 `--ffmpeg`、`--ffprobe`；当前用户环境曾使用 `/Users/yechen/anaconda3/bin/ffmpeg` 和相邻 ffprobe。不可无提示安装软件。

```bash
python3 scripts/magic_import.py inspect --input '/absolute/input/audio'
python3 scripts/magic_import.py convert --input '/absolute/input/audio' --recorded-at '2026-09-29 14:30:00' --output-root '/absolute/staging/output'
```

默认完整转换；仅用户要测试时传 `--seconds 30`。对于多音轨文件，先确认目标音轨，再用 `--audio-stream` 指定从 0 开始的音频流序号。单声道扩展为双声道，多声道默认下混至立体声；若声道承载独立语言/独立录音，应先确认取用方式。无法解码、无音频或受保护输入时停止并解释，勿伪造扩展名。不同输入格式统一解码为 16 kHz 双声道；MP3、AAC/M4A、WAV、FLAC、OGG、AMR 等是否支持取决于本机 FFmpeg。

在工作区生成和校验，然后复制到用户指定的 RECORD 目录（仅在用户希望写入设备时）。需要额外写入权限时请求最小目录权限。保留原音频、已有录音和测试目录；遇到重名停止，不覆盖。复制后核对五个文件的散列；仅移除本次新目录内系统生成的 `._*` 文件。若设备未连接，保留准备好的结果，提示连接，不把缺失挂载点创建成本机目录。若写入中断，不把不完整目录报为成功。

## 不可变的兼容参数

- MP3：MPEG-2 Layer III，16000 Hz，双声道，64 kbps；无 ID3v1/ID3v2、无 Xing/Info 头。
- SBC：16000 Hz，**dual channel（双通道，不是 joint stereo）**，16 blocks，8 subbands，loudness，bitpool 29；128 字节/帧、每帧 128 样本，128 kbps。前三字节 `9c 35 1d`，CRC 随音频变化。
- `.mark` 空文件；`.mode` 精确字节 `{"0":0}`；`.sbc.md5` 为 SBC 文件 MD5 的小写 32 位十六进制，无换行。

普通 FFmpeg 双声道 SBC 默认不能强制这一模式；随包脚本分别编码两个 mono SBC，再按规范合并双通道帧，重新计算 CRC。不得仅改 SBC 头冒充转换。此前 joint stereo SBC 能列入录音列表，但导入失败，App 还会把时长错算成约 69 分钟。

脚本自动检查单声道帧 CRC、合并后的帧长度及头参数，完整解码两个输出，核对时长和生成校验文件。文件复制后仍须进行设备端导入确认；电脑校验不能代替固件测试。最终告知目录、实际时长、时间来源及是否已写入设备，提醒安全弹出，并明确尚未做手机端验证。
